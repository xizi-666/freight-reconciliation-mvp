# 报价模式建议

课程材料的核心原则是：根据客户购买的东西选择计价方式，并确保客户能算清业务收益。截图中市场趋势与政策说明属于课程材料，本文件不将其作为已独立核实的事实。

## 六类模式对本项目的适配

| 模式 | 适配判断 |
|---|---|
| 人天 / T&M | 适合前期探索和接口盘点的成本估算；总成本不确定。 |
| 功能点 / 规模 | 范围明确后可用；需要功能定义和变更控制。 |
| 固定总价 / 整包 | 推荐作为首轮历史回放和小范围并行试点的报价形式。 |
| 订阅 / 年费 | 试点验证后用于持续提供系统能力、维护和支持。 |
| 用量计费 | 适合作为超出配额的补充计价，必须有用量告警和封顶。 |
| 效果付费 / 分成 | 当前不建议直接采用；基线、分母和归因方法尚待确认。 |

## 推荐阶段

1. 验证包：固定总价，约定样本量、两家承运商、系统范围、试点周期、交付物和验收条件。
2. 持续服务：固定实施费 + 有上限的月费/订阅，覆盖接口维护、规则版本、审计和支持。
3. 效果浮动：只有双方确认基线、分母、排除项和归因后再讨论，并设置奖金封顶。不要按争议金额抽成。

## 必须写进报价边界

范围只含只读校验、解释、依据归集和人工交接；不含合同变更认定、赔付认定、自动审批、付款、扣费和未盘点系统接口。成本收益中应扣除集成、维护和人工复核成本。访谈报告中的 18 万元为首期可用预算陈述，不等于供应商报价或成本核算结果。
